## Acceptance Criteria

- [x] PokéAPI service module with functions:
  - `getPokemonList(offset, limit)` — paginated list with basic info
  - `getPokemonByIdOrName(query)` — single Pokémon full detail
  - `getPokemonSpecies(id)` — species data (flavor text, evolution chain URL)
  - `getEvolutionChain(url)` — evolution chain data
  - `getTypeList()` — all Pokémon types
  - `getPokemonByType(type)` — Pokémon filtered by type
- [x] Proper error handling and loading states in service layer
- [x] React Router config with routes:
  - `/` → Home Page
  - `/pokemon/:id` → Detail Page
- [x] Layout component with Header (shared across pages)
- [x] Theme context/provider (light/dark) with localStorage persistence
- [x] Zod schemas for API response validation
