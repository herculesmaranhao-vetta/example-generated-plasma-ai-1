## Acceptance Criteria

- [x] Home page renders at route `/`
- [x] Header with Pokedex logo (text or icon) and theme toggle button (light/dark)
- [x] SearchInput with ~300ms debounce filtering by name or ID
- [x] Select dropdown for Pokémon type filter (all types + each type)
- [x] Responsive grid: 1 col (mobile), 3 col (tablet), 4-5 col (desktop)
- [x] Card per Pokémon showing: official artwork, #ID, capitalized name, type Badges
- [x] "Load More" button at bottom for pagination (offset-based)
- [x] Skeleton cards while loading
- [x] EmptyState when search/filter returns no results
- [x] Error handling with EmptyState for API failures
- [x] Lazy loading for Pokémon images
- [x] Clicking a card navigates to `/pokemon/:id`
- [x] Theme toggle persists preference in localStorage
